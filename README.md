# VicterVbot
VicterVbot is a full-featured Twitch bot built for streamers, communities, and Fortnite tournament organizers. It combines chat commands, automation, moderation-oriented tools, tournament tracking, and community features in one platform.
## Features
- Twitch chat commands and automated responses
- Stream and community automation
- Fortnite tournament-focused statistics and updates
- Tournament schedules, tracking, and player tools
- Tools for streamers and tournament organizers
- Web dashboard for managing bot features
## Links
- [Live website](https://victervbot.com)

## Technology
The public project uses TypeScript, CSS, and JavaScript. The bot’s private runtime and operational source are maintained separately in the private `VicterVbot-cloud` repository.
