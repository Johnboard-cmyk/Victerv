# VicterVbot
VicterVbot is a full-featured Twitch bot with automation, chat commands, and Fortnite-focused tournament features, statistics, and community tools.
## Highlights
- Twitch chat commands and automation
- Fortnite tournament-focused statistics and updates
- Community tools for streamers and tournament organizers
- Public project site: https://victervbot.com
## Project
This repository contains the public web project built with TypeScript, CSS, and JavaScript.
